DRO FIRST USE

Use ABS mode in inches. Coordinates describe the tool relative to the work; the table moves the opposite way. Axis Set assigns the current position's coordinate; Preset stores a destination and does not establish this datum.

For an opposed-edge datum, use the same finder for both actual edges:

  1. Pick up each actual edge and compensate its signed contact.
  2. Use their actual midpoint (edge 1 + edge 2) / 2; set the stated datum there, not at half an assumed stock width.
  3. Before a check jog, raise Z only until the tip clears the work and all clamps; return to the contact reading before lowering, without another Axis Set.

This setup's paper is 0.002 in: stop at light drag and include that actual thickness with the contact-side sign in Axis Set.

From X -0.6, jog +X 0.25 in: it must read -0.35; -0.85 means reversed — STOP and correct the direction before re-establishing the datum.

X and Y check jog
  1. raise Z only until the tool clears the work and clamps, without changing the axis under test.
  2. jog the table by the stated check-jog amount in the positive tool-relative direction; the display must read the listed value.
  3. jog back to the Axis Set value again, then lower; do not Axis Set again.
